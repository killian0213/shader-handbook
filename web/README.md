# 手册网页版

把 `shader-handbook/` 里的 Markdown 直接读出来渲染成网页，并且**让书里的代码当场跑起来、当场调**。
Markdown 原文一个字都没改，网页只是它的另一个"读法"。

## 启动

```bash
python web/serve.py          # 默认 8000 端口，会自动开浏览器
python web/serve.py 8080     # 换端口
```

然后访问 <http://localhost:8000/web/>。

> 必须用这个本地服务器打开。直接双击 `index.html` 会因为浏览器的 `file://` 限制读不到章节文件。
> 需要支持 WebGL2 的浏览器（Chrome / Edge / Firefox 近几年的版本都行）。

新增或改名章节后跑一次：

```bash
python web/build_manifest.py
```

## 网页能做什么

- **左侧全书目录、右侧本章小节目录**，顶栏可以全文搜索（按 `/` 聚焦搜索框）。
- **配色三选一**：顶栏「浅 / 纸 / 深」按钮循环切换浅色、纸黄、深色，选择记在 `localStorage` 里。
  也可以用 `?theme=sepia`（`light` / `sepia` / `dark`）直接指定。
- **正文字号四档**：顶栏「A」按钮在小 / 中 / 大 / 特大之间循环，只影响正文，不动侧栏和工具条。
- **代码块直接出画面**。滚动到哪儿，哪儿的 shader 就开始跑；离开视野自动停，不烧显卡。
- **拖动画面** = Shadertoy 里的 `iMouse`。3D 预览里左右拖是转相机，上下拖是升降。
- **滑块调参**。两种滑块：
  - 橙色变量名来自源码里的 `#define` / `const float`，拖动会**改写代码并重新编译**；
  - 自动外壳的函数参数（比如 `sdSphere` 的半径 `s`）是真 uniform，拖动即时生效。
- **✎ 编辑**：就地改代码，停手 0.35 秒自动重编译，编译错误会指回你写的那一行。
- **⚡ 沙盒**：全屏的编辑器 + 预览，可以从手册示例载入起点。
- **点橙色的作品路径**（比如 `001676-Xds3zN-Raymarching_-_Primitives/image.glsl`）会弹出语料原文，还能试着直接运行。

## 半截代码是怎么跑起来的

手册里大多数代码块不是完整 shader——有的是一个函数，有的是从别处摘出来的几行语句。
阅读器会先判断这块代码属于哪一类，再套上对应的外壳：

| 代码块长什么样 | 处理方式 |
| --- | --- |
| 自带 `mainImage` | 原样编译 |
| 只有函数定义 | 按函数签名挑一个**预览外壳**（见下表） |
| 散装语句 | 塞进一个 `mainImage`，并补上 `uv` / `col` / `p` 之类它假定已经存在的变量 |
| 以 `return xxx;` 结尾 | 当成某个函数的函数体，包成函数再预览 |

外壳按第一个参数和返回值类型挑：

| 签名 | 预览 |
| --- | --- |
| `float f(vec2)` | iq 式 SDF 可视化（内外配色 + 等距环 + 零等值线），可切灰度场 / 调色板 |
| `vec3 f(vec2)` | 直接当颜色画 |
| `vec2 f(vec2)` | 当域变换，画一张被扭曲的棋盘 |
| `float f(vec3)` | 当 `map()`，用一个小 raymarcher 打光渲染 |
| `vec3 f(vec3 ro, vec3 rd)` | 当渲染函数，配一台环绕相机 |
| `float f(float)` | 画函数曲线 |
| `vec3 f(float)` | 画调色板色带 |
| `mat2 f(float)` | 把变换作用在测试图案上 |

代码里引用了但没定义的常见工具函数（`hash*` / `noise` / `fbm` / `rot` / `smin` / `palette` /
`calcNormal` / `softshadow` …）会自动注入一份实现。注入是按**函数名 + 参数个数 + 首参类型**判断的，
所以你自己写了 `noise(vec2)` 时，`noise(vec3)` 仍然会被补上。

外壳和注入的代码都不是原文的一部分——画面下方那行灰字会告诉你用的是哪种外壳。

## 跑不起来的代码块 / 黑屏怎么处理

阅读器对"教学片段"分三层处理，避免占一大块黑画布：

1. **能编译、但没写 `col` / `fragColor` 的语句片段**  
   自动把最后算出来的那个变量可视化出来（距离场 / 灰度 / 色带，或 `vec2` 的红绿图）。  
   画面下方灰字会写「自动可视化变量 xxx」，并可切换显示模式。
2. **能编译、但画面几乎全黑（依赖缺失上下文）**  
   渲染一两秒后会自动收起画布，徽章改成「教学片段」，提供「在沙盒里补全」和「仍要显示画面」。
3. **根本编译不过**  
   自动预览静默失败；点「▶ 试运行」才显示编译器原文。  
   中文占位符、`sdSomething(...)`、多 Pass 的 `Buf` 多半落在这一类。

点「⚡ 在沙盒里补全」可以带着这段代码去沙盒接着写。

> **排错提示**：若某一章突然所有代码块都变成裸的 \`\`\` 文本、也没有预览，多半是该 `.md` 被存成了 CRLF。  
> 阅读器已自动把 `\r\n` 归一成 `\n`；若你在本机用脚本重写章节，请用二进制/`newline=''` 写 LF，避免再次踩坑。

当前覆盖率（`node web/tools/validate.js`）：**341 个 GLSL 代码块里 244 个能直接出图（72%）**，
剩下的基本都是上面这类真·伪代码；再加上自动可视化，教学过程中的"半截代码"也多数能看出在算什么。

## 语料作品的限制

弹窗里的「运行这个作品」只跑 Image 这一个 Pass：

- 多 Pass 作品（Buffer A~D）的通道读到的是程序化噪声，不是上一帧；
- 原作用的贴图、立方体贴图、音频、键盘输入，同样用噪声顶替。

所以画面经常和原作不一样，甚至直接编译失败。它的用处是**看代码**，顺手能跑就是赚到。

## 目录

```
web/
  index.html          页面骨架
  app.css             样式
  manifest.json       章节清单（build_manifest.py 生成）
  serve.py            本地服务器
  build_manifest.py   扫描 shader-handbook/ 生成清单
  js/
    md.js             Markdown 渲染（表格、公式、代码块抽取）
    glsl-lib.js       代码分析、自动外壳、工具函数注入、语法高亮
    runtime.js        WebGL2 运行时（共享一个 GL 上下文，blit 到各个 2D canvas）
    app.js            路由、章节挂载、代码块交互、沙盒
  tools/
    validate.js       用 glslangValidator 离线跑一遍全书代码块，统计覆盖率
    dump.js           打印某个代码块生成的完整 shader，调外壳时用
    probe.html        WebGL2 环境自检页
```

`runtime.js` 只开一个 WebGL 上下文：浏览器对同时存在的 WebGL 上下文有数量上限（约 16 个），
而一章可能有四十个代码块。所以所有预览共用一个隐藏的 GL canvas，画完再 `drawImage` 拷到各自的 2D canvas 上。
