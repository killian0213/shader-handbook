# Shadertoy 效果实现手册

> 一本从 2675 个真实 Shadertoy 作品（4800 个 GLSL 文件、35.1 MB 源码）中逆向总结出来的学习手册。
>
> 它要回答的**唯一问题**是：**我脑子里想到一个效果，怎么把它做出来？**

> 📺 **想边看边跑？** 在线网页版（随时打开）：  
> <https://killian0213.github.io/shader-handbook/>  
> 本地调试：`python web/serve.py`，然后打开 <http://localhost:8000/web/>。

## 这本手册和别的 Shader 教程有什么不同

大部分教程教你「GLSL 语法」和「几个经典例子」。看完之后你会写 `smoothstep`，但面对"我想做一个雨打玻璃的效果"依然完全无从下手。

问题不在于你不会语法，而在于你缺少两样东西：

1. **一套把"想要的画面"翻译成"可计算的数学"的拆解方法**。这是本手册的第 0 章，也是全书的核心。
2. **一个足够大的技法词汇表**。就像写作需要词汇量一样，做 shader 需要你脑子里存着几百个"这种感觉可以用那个技巧做出来"的条目。

这本手册的写法是：先教你拆解方法，再用真实作品把技法词汇表一条条填满。**每一个技法都注明了它出自语料库里的哪个作品**，你可以随时打开原文对照。

## 这份语料长什么样

先给你一个客观的全景，这决定了本手册的章节权重——**我们把篇幅花在真实世界里真正高频的东西上**，而不是凭印象。

**作品规模**

| 指标 | 数值 |
|---|---|
| 作品总数 | 2675 |

**Pass 类型分布**：`image` 2675、`buffer` 1502、`common` 481、`sound` 94、`cubemap` 48。

也就是说：**三分之二的作品只用一个 Pass**。不要一上来就研究多 Pass 架构，绝大多数惊艳效果是一个 `mainImage` 函数写出来的。

## 怎么用这本手册

### 如果你完全零基础

按顺序读 **第 0 章 → 第 5 章**，每章都动手把代码敲进 Shadertoy 跑一遍。不要只看。这部分大约需要两到三周，读完你能独立做出所有 2D 效果。

然后读 **第 6 章 → 第 9 章**（3D raymarching），这是整个领域的分水岭。读完你能做出语料库里 40% 的作品。

之后按兴趣挑章节读。若只想尽快做出具体画面，也可以读完第 0–1 章后直接跳进 **第 18 章 + 附录 B**，用配方和语料路径驱动练习。

### 如果你已经会一点

直接看 **第 0 章**（拆解方法论）和 **第 18 章**（效果配方大全）。第 0 章给你方法，第 18 章给你词汇表。中间的章节当作参考手册，需要时再查。

卡住某个具体画面时：先在第 18 章找到对应配方 → 打开附录 B 的语料路径对照 → 需要函数就抄附录 A。

### 如果你是来查资料的

看 **附录 A**（函数速查表）和 **附录 B**（按效果检索语料）。文件夹命名规则与点赞排序说明也在附录 B。

## 建议阅读顺序

1. **第 0 章**建立「场」思维，并跟做合成波日落（这是全书的心法）。
2. **第 1 章**弄清 Shadertoy 的 uniform 与 Pass。
3. 按基础路径读 **第 2–9 章**；或带着具体画面目标直接去 **第 18 章**查配方。
4. **附录 B**打开语料原文对照；函数不够用时抄 **附录 A**。
5. 画面「能跑但不稳 / 太慢」时再读 **第 19 章**。

语料原文都在仓库的 `shaders/shaders/` 下，文件夹名 = `点赞数-ShaderID-标题`。手册里每一处 `📄 出自 ...` 都可以直接对着打开。

## 一个约定

手册里的每段代码都标注了来源，格式是：

> 📄 出自 `002224-Ms2SD1-Seascape/image.glsl`（TDM）

文件夹名的开头数字是该作品在 Shadertoy 上的点赞数（补零到 6 位），所以 `002224-` 开头的是全语料最受欢迎的作品。你可以直接在 `shaders/shaders/` 下找到它。

标注为 **「合成示例」** 的代码是我为了讲解而重新组织的，不是语料原文。

手册里的 GLSL 代码块有两类：

- **可编译块**（无标记，或 `<!-- glsl-from: examples/... -->`）：已用 `glslangValidator` 按 GLSL ES 3.00 实际编译验证，可直接复制到 Shadertoy。
- **教学片段**（`<!-- glsl-skip -->`）：为讲清思路而摘的半截代码 / 伪代码，不单独编译；请按正文说明嵌入完整 shader 使用。
