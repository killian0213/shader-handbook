## 16.1 程序化声音：`mainSound`

除了 `mainImage`，你可以加一个 **Sound Pass**，签名是：

<!-- glsl-skip -->
```glsl
vec2 mainSound(int samp, float time)
```

返回值是立体声 `(left, right)`，幅度大约在 `[-1, 1]`。平台按 `iSampleRate`（通常 44100）逐采样调用。

### 最小哔哔声

```glsl
vec2 mainSound(int samp, float time)
{
    float freq = 440.0;
    float amp  = 0.2 * exp(-3.0 * time); // 简单衰减，避免一直响
    float s = sin(6.283185 * freq * time) * amp;
    return vec2(s);
}
```

### 从音符到频率

```glsl
float noteHz(float midiNote)
{
    // A4 = 69 → 440 Hz
    return 440.0 * pow(2.0, (midiNote - 69.0) / 12.0);
}
```

### 合成常用积木

| 积木 | 代码直觉 | 听感 |
|---|---|---|
| 正弦 | `sin(ωt)` | 纯净 |
| 方波 | `sign(sin(ωt))` | 8-bit 硬 |
| 锯齿 | `fract(f*t)*2-1` | 明亮弦乐感 |
| 噪声 | `hash(floor(t*sr))` | 打击/踩镲 |
| ADSR | 分段包络乘幅度 | 乐句呼吸 |

### 同步画面

Sound Pass **不能**直接读 Buffer（历史上限制多）。常见同步策略：

1. **同一套时间函数**：画面和声音都用 `iTime` / 同一 BPM 公式算「第几拍」。
2. **把声音烘焙成纹理** 再当 `iChannel` 频谱用（或用 SoundCloud / 麦克风输入）。
3. 看高赞音乐作品怎么对齐 drop：`000556-ldXXDj-Music_-_Pirates`（iq）、`000537-XtlSD7-_SIG15_Mario_World_1-1`（knarkowicz）。

> 📄 程序化配乐典范：`000556-ldXXDj-Music_-_Pirates`、`000138-t3cfWf-Music_-_Always_With_Me`

写音乐时先搞定 **BPM 时钟**：

<!-- glsl-skip -->
```glsl
float bpm = 128.0;
float beat = time * bpm / 60.0;
float cell = floor(beat);
float local = fract(beat);
```

鼓点用 `exp(-local*k)` 做短包络；旋律用 `mod(cell, 16)` 查 note 表。

## 16.2 FFT 与波形：`iChannel` 音频纹理

把音频（麦克风 / SoundCloud / 内置音）绑到 `iChannel0` 时，得到一张 **512×2** 的特殊纹理：

| 行 | 含义 |
|---|---|
| `y=0` | FFT 频谱，512 个 texel，低频在左 |
| `y=1` | 时域波形，512 个 mono 采样 |

> 📄 出自 `000219-Xds3Rr-Input_-_Sound/image.glsl`（iq）——官方教材级示例

<!-- glsl-skip -->
```glsl
    int tx = int(uv.x*512.0);
	float fft  = texelFetch( iChannel0, ivec2(tx,0), 0 ).x; 
    float wave = texelFetch( iChannel0, ivec2(tx,1), 0 ).x;
	vec3 col = vec3( fft, 4.0*fft*(1.0-fft), 1.0-fft ) * fft;
	col += 1.0 -  smoothstep( 0.0, 0.15, abs(wave - uv.y) );
	fragColor = vec4(col,1.0);
```

### 实践建议

- **用 `texelFetch`，不要用 `texture` 插值频谱**——相邻频段插值会糊掉峰值。
- 低频能量通常更大；可视化时对 `fft` 做 `pow(fft, 0.5)` 或分频段加权。
- 「音乐驱动位移」：取某几个频段平均当系数：

<!-- glsl-frag -->
```glsl
float bass = 0.0;
for (int i = 0; i < 8; i++)
    bass += texelFetch(iChannel0, ivec2(i, 0), 0).x;
bass /= 8.0;
float pulse = smoothstep(0.2, 0.6, bass);
```

- 高赞视觉向：`000500-Msl3Rr-Cubescape`、`000407-4slGz4-Demo_-_Volumetric_Lines`、`000127-dtl3Dr-3D_Audio_Visualizer`。

### SoundCloud / 麦克风

通道类型选 SoundCloud 或 Microphone，采样方式相同（仍是 512×2）。麦克风适合互动装置；注意浏览器权限与静音默认。

## 16.3 文字与字体纹理

Shadertoy 没有 `DrawString`。写字的路只有几条：

### ① 字体纹理 + UV 切格

把一张 bitmap font 绑到 `iChannel`，按字符 ASCII 选格子：

```glsl
float fontSample(vec2 uv, int charCode)
{
    // 假设 16×8 字符图集
    vec2 cell = vec2(float(charCode % 16), float(charCode / 16));
    vec2 fuv = (cell + fract(uv)) / vec2(16.0, 8.0);
    return texture(iChannel0, fuv).a;
}
```

### ② 程序化 SDF 字体

用线段 / 胶囊 SDF 拼字母。贵，但可任意缩放、可 glow。

> 📄 `000122-4s3XDn-Shadertext_proportional_spacing`、`000137-Mt2GWD-96-bit_8x12_Font`（位打包字体）、`000129-MsXSRn-runes`

### ③ 位打包（高尔夫与复古风常用）

把字形塞进 `uint` / `float` 的比特里，按像素位测试：

<!-- glsl-skip -->
```glsl
// 概念：glyph 是 5×5 点阵，存在 25 bit 里
bool on = ((glyph >> (y * 5 + x)) & 1) == 1;
```

> 📄 `000137-Mt2GWD-96-bit_8x12_Font`（Flyguy）

### ④ ASCII 艺术

对场景取亮度，映射到字符集 `" .:-+=#@"`，再采样字体。

> 📄 `000152-lssGDj-Ascii_Art`（movAX13h）、`000153-XsSGzG-AsciiArt_Teapot_-_1117ch`

### 终端模拟器级文字

> 📄 `000272-XdtfzX-vt220_coding_at_night_edition`（sprash3，3 pass）

多 Pass 存字符缓冲区，Image 负责 CRT 显示。这是「文字 + 仿真状态 + 后期」的交叉题，适合学完第 13、15 章再啃。

## 16.4 键盘纹理

把 **Keyboard** 绑到某个 `iChannel` 后，得到一张特殊图：

| 行 | 含义 |
|---|---|
| `y=0` | 当前是否按住（256 键） |
| `y=1` | 本帧是否刚按下（keypress 边沿） |
| `y=2` | 开关态（按一次翻转） |

**Texel 的 x = ASCII / keyCode。**

> 📄 出自 `000127-lsXGzf-Input_-_Keyboard/image.glsl`（iq）

<!-- glsl-skip -->
```glsl
const int KEY_LEFT  = 37;
const int KEY_UP    = 38;
const int KEY_RIGHT = 39;
const int KEY_DOWN  = 40;

// 当前按住
texelFetch( iChannel0, ivec2(KEY_LEFT,0), 0 ).x
// 刚按下
texelFetch( iChannel0, ivec2(KEY_LEFT,1),0 ).x
// 开关
texelFetch( iChannel0, ivec2(KEY_LEFT,2),0 ).x
```

### 封装成好用的函数

```glsl
bool keyDown(int k){ return texelFetch(iChannel1, ivec2(k,0), 0).x > 0.5; }
bool keyHit (int k){ return texelFetch(iChannel1, ivec2(k,1), 0).x > 0.5; }
bool keyTog (int k){ return texelFetch(iChannel1, ivec2(k,2), 0).x > 0.5; }
```

### 典型用途

- **相机 WASD**：在 Buffer 里读键，更新相机位置状态（必须多 Pass，因为要积分）
- **开关模式**：`keyTog(32)` 空格切换自动/手动
- **游戏**：`000459-MddGzf-Bricks_Game`、`000326-Ms3XWN-Pacman_Game`、`000211-wtS3W3-Sunset_Drive_Unlimited`

Meta CRT 用键盘控制参数，并把 keyboard 绑在 Buffer A：

> 📄 出自 `000400-4dlyWX-Meta_CRT/meta.json` — `"type": "keyboard"`

**务必 `texelFetch` + 整数坐标**；过滤设 nearest。

## 16.5 Cubemap Pass

`mainCubemap` 让你渲染到立方体贴图六面，之后当 `samplerCube` 用——环境反射、天空盒、IBL。

<!-- glsl-skip -->
```glsl
void mainCubemap(out vec4 fragColor, in vec2 fragCoord, in vec3 rayOri, in vec3 rayDir)
```

- `rayDir`：该 texel 对应的方向（已按面摆好）
- 你按方向返回「那个方向上看见的颜色」

### 最小天空盒

```glsl
void mainCubemap(out vec4 fragColor, in vec2 fragCoord, in vec3 ro, in vec3 rd)
{
    float t = 0.5 + 0.5 * rd.y;
    vec3 sky = mix(vec3(0.6, 0.7, 0.9), vec3(0.1, 0.2, 0.5), t);
    fragColor = vec4(sky, 1.0);
}
```

Image 里：

<!-- glsl-frag -->
```glsl
vec3 refl = reflect(rd, n);
vec3 env = texture(iChannel0, refl).rgb; // iChannel0 = Cubemap
```

> 📄 Meta CRT 含 `cubemap.glsl`；环境反射类作品常用此路径。语料统计 cubemap pass 共 48 个——不多，但做金属/车漆时非常香。

## 16.6 鼠标相机

### 轨道相机（最常用）

<!-- glsl-skip -->
```glsl
void mainImage(out vec4 fragColor, in vec2 fragCoord)
{
    vec2 uv = (2.0 * fragCoord - iResolution.xy) / iResolution.y;

    // 鼠标 → 角度；未按下时给默认演示角度
    vec2 m = iMouse.xy;
    if (iMouse.z < 0.0 && iMouse.xy == vec2(0.0))
        m = 0.5 * iResolution.xy; // 从未点击
    float an = (m.x / iResolution.x - 0.5) * 6.283185;
    float el = (m.y / iResolution.y - 0.5) * 3.0;

    vec3 ta = vec3(0.0);
    vec3 ro = ta + vec3(cos(el)*sin(an), sin(el), cos(el)*cos(an)) * 3.0;

    // lookAt
    vec3 ww = normalize(ta - ro);
    vec3 uu = normalize(cross(ww, vec3(0,1,0)));
    vec3 vv = cross(uu, ww);
    vec3 rd = normalize(uv.x*uu + uv.y*vv + 1.5*ww);

    vec3 col = render(ro, rd);
    fragColor = vec4(col, 1.0);
}
```

### 一阶积分相机（需 Buffer）

按住拖动应有惯性时：Buffer 存 `yaw, pitch, yawVel, pitchVel`，每帧读键盘/鼠标加速度，阻尼积分。这就是「交互 + 第 13 章状态」的合流。

### iMouse 语义速记（详见第 1 章）

| 条件 | 含义 |
|---|---|
| `iMouse.z > 0` | 按住 |
| `iMouse.w > 0` | 本帧刚按下 |
| `iMouse.xy` | 当前位置（松开后保持） |

> 📄 工具集：`000356-llySRh-iResolution_iMouse_iDate_etc`（FabriceNeyret2）
> 📄 官方鼠标：`000129-Mss3zH-Input_-_Mouse`

### 绘画式交互

鼠标当笔刷写进 Buffer（第 13 章拖尾模板）。高赞：`000451-fljBWc-Liquid_Toy`、`000234-sf23W1-Mouse-Paint_Eroded_Mountains`。

## 16.7 UI 叠加层

在 Image 最后画控件：色块按钮、滑条、文字。命中测试用「像素是否落在矩形里」+ 鼠标点击写状态到 Buffer。

> 📄 `000201-Xs2cR1-Super_Shader_GUI_98`（P_Malin）、`000290-3tBGRm-UI_noise_halo`、`000620-4sSfzK-_SH17C_Physically_Based_Shading`（带 UI 的 PBR 教程）

模式：

```
Buf A: 存滑条值（几个 texel）
Image: 读值渲染场景；最后 overlay 画 UI；
       若点击落在滑条上，下一帧 Buf A 更新（实际在 Buf A Pass 里做点击检测）
```

点击检测必须放在 **会写回状态的 Buffer**，不能只在 Image 里改——Image 不反馈。

## 16.9 常见坑

| 坑 | 症状 | 修复 |
|---|---|---|
| 音频用 `texture` 插值 | 频谱糊、节拍弱 | `texelFetch` |
| 键盘过滤 linear | 键状态变成灰色 | nearest + fetch |
| 只在 Image 里改状态 | 交互「当天忘」 | 状态写入 Buffer |
| `mainSound` 幅度 >1 | 爆音失真 | `tanh` 或 clamp |
| 字体 UV 未按宽高比 | 字被拉扁 | 与场景同一套 uv 规范 |
| 从未点击鼠标 | 相机跳左下角 | 默认角度分支 |

## 16.10 精读：iq《Music - Pirates》的声音结构

> 📄 出自 `000556-ldXXDj-Music_-_Pirates/sound.glsl`（iq，556 likes）

这不是「一个 sin」，而是完整编曲思维：

<!-- glsl-skip -->
```glsl
float instrument( float freq, float time )
{
    // 多个谐波 sin(n*ωt) * exp2(-衰减*n*...)
    // 再加一点立方非线性 y += 0.35*y*y*y;
    // attack: clamp(time/0.004,0,1)
    ...
}

vec2 mainSound( in int samp, float time )
{	
    time = mod( time, 60.0 );
    vec2 y = vec2(0.0);
    y += vec2(0.7,0.3)*doChannel1( time );
    y += vec2(0.3,0.7)*doChannel2( time );
	y *= 0.1;
	return y;
}
```

读代码时抓三条：

1. **`instrument(freq,time)`**：同一发声模型，不同音符只改 `freq` 与触发时刻。
2. **多谐波 + 指数衰减**：音色；`y^3` 非线性 = 便宜的「温暖饱和」。
3. **左右声道不同权重**：`vec2(0.7,0.3)` vs `vec2(0.3,0.7)` → 简单立体声分离。
4. **`#define D(a) b+=float(a);if(t>b)x=b;`**：用宏压缩「乐谱时间表」——这是声音高尔夫，可读性让位于序列数据密度。

自己写第一首时，不要抄宏谱。用数组：

<!-- glsl-skip -->
```glsl
const int N = 8;
float notes[8] = float[](60.,62.,64.,65.,67.,65.,64.,62.);
float beat = time * 2.0; // 120 BPM 八分音符
int idx = int(mod(beat, float(N)));
float local = fract(beat);
float freq = 440.0 * pow(2.0, (notes[idx] - 69.0) / 12.0);
float env = exp(-local * 6.0) * smoothstep(0.0, 0.01, local);
float s = sin(6.283185 * freq * time) * env * 0.2;
return vec2(s);
```

画面 Pass 用同一个 `beat = iTime * 2.0` 驱动闪烁，音画就锁上了。

## 16.11 精读：键盘官方示例的三层 HUD

> 📄 出自 `000127-lsXGzf-Input_-_Keyboard/image.glsl`

iq 在同一方向键位置画了三层反馈：

- **实心圆亮度** ← 行 0 按住态
- **外环细线** ← 行 1 keypress
- **中环** ← 行 2 toggle

这是调试输入的最好教具：接上键盘通道后先复现这个 HUD，确认浏览器焦点在 canvas 上、键码没错，再接相机逻辑。

常见键码速查：

| 键 | 码 | 键 | 码 |
|---|---|---|---|
| 左/上/右/下 | 37/38/39/40 | A/W/D/S | 65/87/68/83 |
| 空格 | 32 | Shift | 16 |
| 0–9 | 48–57 | Enter | 13 |

不同浏览器对部分键可能有差异；用官方示例校准。

## 16.12 鼠标绘画 + 音频反应的迷你项目

把第 13、15、16 章焊成一个周末作业：

```
Buf A: 反馈画布。鼠标喷颜料；bass 大时喷口变粗、颜色偏亮
Image: 读 A，加轻微 bloom（可临时用 mip 糊弄）， tonemap，扫描线
Sound: 可选；或用麦克风 FFT 当 iChannel1
```

<!-- glsl-frag -->
```glsl
// Buffer A 核心
vec2 uv = fragCoord / iResolution.xy;
vec3 prev = texture(iChannel0, uv).rgb;

float bass = 0.0;
for (int i = 0; i < 8; i++)
    bass += texelFetch(iChannel1, ivec2(i, 0), 0).x;
bass *= 0.125;

vec3 paint = vec3(0.0);
if (iMouse.z > 0.0) {
    float r = 0.02 + 0.05 * bass;
    float d = length(uv - iMouse.xy / iResolution.xy);
    paint = vec3(0.2 + bass, 0.4, 1.0) * exp(-d * d / (r * r));
}
fragColor = vec4(max(paint, prev * 0.96), 1.0);
```

## 要点回顾

1. **`mainSound(samp,time)→vec2`** 写立体声；用 BPM 时钟与画面对齐。
2. **音频纹理 512×2**：行 0=FFT，行 1=波形；`texelFetch` 读取。
3. **文字**靠字体纹理、SDF 笔画或位打包；无系统 API。
4. **键盘三行**：按住 / 边沿 / 开关；x=键码。
5. **Cubemap Pass** 产出 `samplerCube`，供反射与天空。
6. **鼠标相机**注意未点击默认值；要有记忆就必须 Buffer。
